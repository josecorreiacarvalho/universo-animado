# 🎬 Universo Animado

O **Universo Animado** é uma landing page responsiva inspirada em desenhos animados clássicos que marcaram gerações.

O projeto reúne personagens conhecidos, informações sobre os desenhos e links para assistir a conteúdos relacionados.

## 🚀 Site publicado

Acesse o projeto online pelo GitHub Pages:

**https://josecorreiacarvalho.github.io/universo-animado/**

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- jQuery
- Font Awesome
- ScrollReveal

## ✨ Funcionalidades

- Layout responsivo para desktop e dispositivos móveis
- Menu de navegação
- Seção com desenhos clássicos
- Cards com informações dos personagens
- Links para vídeos
- Animações durante a navegação
- Seção Nostalgia
- Links para redes sociais

## 📱 Responsividade

O projeto foi desenvolvido para se adaptar a diferentes tamanhos de tela, permitindo a navegação tanto pelo computador quanto pelo celular.

## 📚 Objetivo do projeto

Este projeto foi desenvolvido com fins de estudo e prática de desenvolvimento front-end, trabalhando conceitos de HTML, CSS, JavaScript, responsividade e publicação de sites com GitHub Pages.
